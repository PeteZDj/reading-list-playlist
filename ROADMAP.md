# Roadmap

This repo is part of a broader PeteZDj calibre plugin direction:

- Build practical, optimized calibre plugins from real library pain points.
- Keep changes small, inspectable, and compatible with calibre's existing data
  model.
- Give clear credit and preserve upstream licenses when deriving from existing
  plugins.
- Prefer focused workflow improvements over broad rewrites.

Near-term ideas:

- Make Genre/Tag Browser behavior configurable from the plugin UI.
- Add a diagnostics action that reports relevant calibre Tag Browser settings.
- Package releases as GitHub release assets.
- Create a repeatable template for future derivative or original calibre plugins.
